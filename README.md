# نبض للرعاية الطبية (Nabd Medical Care)
### موقع ويب ثابت (Static Demo) للمراكز الطبية وحجز الاستشارات الطبية

موقع إلكتروني ثابت احترافي مبني بالكامل باستخدام **HTML5 + CSS3 + Vanilla JavaScript**، بدون أي أطر عمل أو مكتبات خارجية ثقيلة وبدون كود سيرفر، جاهز للتشغيل الفوري والرفع المباشر على **GitHub Pages**.

---

## 🌟 مميزات الموقع
- **ثنائي اللغة بالكامل (عربي + إنجليزي):** تبديل سلس وفوري للغة واتجاه الصفحة (`rtl` / `ltr`) والخطوط وحفظ التفضيل في المتصفح.
- **محرك حجز متكامل (4 خطوات):** اختيار التخصص والطبيب ونوع الاستشارة، اختيار اليوم والوقت من فترات مجدولة، نموذج بيانات مع تحقق من صيغة أرقام الهاتف المصرية، ملخص تأكيد، وتوليد رقم مرجعي للحجز مع زر إرسال مباشر عبر الواتساب.
- **حفظ محلي للحجوزات (Local Storage):** صفحة "حجوزاتي" لإدارة المواعيد، الإلغاء، أو إعادة الجدولة، مع شارة عدد المواعيد في شريط التنقل.
- **تصفية وبحث متقدم للأطباء:** بحث فوري بالاسم، فلترة حسب التخصص، نوع الكشف، الجنس، والتوفر اليومي، مع ترتيب بالتقييم أو السعر.
- **تصميم طبي هادئ وعصري:** متوافق مع كافة أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة)، مع احترام إمكانية الوصول وتباين الألوان.
- **مهيأ لمحركات البحث (SEO):** عناوين دقيقة، وسوم OpenGraph و Twitter Cards، وبيانات وصفية منظمة (Schema.org) بصيغة `MedicalClinic` و `Physician` و `FAQPage`.

## ⚙️ التعديل والتخصيص السريع (عبر `js/data.js`)

كل إعدادات الموقع مركزية وموجودة في أول ملف `js/data.js`:

### 1. تعديل بيانات التواصل ورقم الواتساب
افتح `js/data.js` وعدل كائن `CONFIG`:
```javascript
const CONFIG = {
  clinicNameAr: 'نبض للرعاية الطبية',
  clinicNameEn: 'Nabd Medical Care',
  hotline: '16890',                  // الخط الساخن
  phone: '+20 2 2345 6789',          // رقم الهاتف
  whatsappNumber: '201234567890',    // ضع رقم الواتساب بصيغة دولية بدون علامة +
  email: 'info@nabd-care.example.com',
  // ضع رابط حسابك في Formspree لاستقبال رسائل التواصل والحجوزات مجاناً
  formspreeContactEndpoint: 'https://formspree.io/f/mqkvrkzl',
  formspreeBookingEndpoint: 'https://formspree.io/f/mqkvrkzl'
};
```

### 2. تعديل بيانات الأطباء والأسعار والمواعيد
في مصفوفة `DOCTORS` داخل `js/data.js`:
- لتعديل الأسعار: غيّر قيم `fees.clinic` و `fees.video` و `fees.phone`.
- لتعديل أوقات العمل: عدل مصفوفة `timeSlots` (مثل: `['10:00 AM', '02:00 PM', ...]`).
- لتعديل أيام الكشف: عدل مصفوفة `scheduleDays` حيث:
  - `0`: الأحد | `1`: الإثنين | `2`: الثلاثاء | `3`: الأربعاء | `4`: الخميس | `6`: السبت (يوم الجمعة `5` معطل افتراضياً لطوارئ العيادات).
- لتحديد التوفر اليومي: ضع `availableToday: true` أو `false`.

### 3. تعديل الألوان والهوية البصرية
افتح ملف `css/style.css` وعدل المتغيرات في `:root`:
```css
:root {
  --teal: #0E8A8A;       /* اللون الأساسي للأزرار والعناصر النشطة */
  --navy: #0B3C5D;       /* اللون الكحلي للعناوين والفوتر */
  --mint: #E6F5F3;       /* خلفيات الأقسام الهادئة */
  --coral: #FF6B5E;      /* شارات التوفر السريع والتنبيهات */
  --white: #FFFFFF;
  --light: #F6FAFA;
  --text: #1F2D3D;
}
```

### 4. تعديل النصوص والقواميس (عربي / إنجليزي)
جميع نصوص الموقع معرفة داخل كائن `I18N.ar` و `I18N.en` في `js/data.js` ومربوطة بالعناصر عبر السمة `data-i18n`. يمكنك تعديل أي نص في مكان واحد وسينعكس فوراً على كامل الموقع.

## 🚀 طريقة الرفع على GitHub وتفعيل GitHub Pages

الموقع مصمم بمسارات نسبية نقية (`./`) ولا يحتاج لأي خطوات بناء (Build) أو خادم خلفي:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في [GitHub](https://github.com) باسم `nabd-medical-care`.
2. ارفع جميع ملفات ومجلدات المشروع إلى المستودع:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Nabd Medical Care"
   git branch -M main
   git remote add origin https://github.com/USERNAME/nabd-medical-care.git
   git push -u origin main
   ```
3. توجه إلى إعدادات المستودع على GitHub:
   - اذهب إلى **Settings** > **Pages** (في القائمة الجانبية).
   - تحت قسم **Build and deployment** اختر:
     - **Source**: `Deploy from a branch`
     - **Branch**: اختر `main` واجعل المجلد `/(root)`
   - اضغط **Save**.
4. خلال دقيقة أو دقيقتين سيظهر رابط موقعك المباشر في الأعلى بصيغة:
   `https://USERNAME.github.io/nabd-medical-care/`
5. سيعمل الموقع مباشرة بجميع صفحاته وصوره والحجز والتبديل بين اللغتين بنجاح تام!
